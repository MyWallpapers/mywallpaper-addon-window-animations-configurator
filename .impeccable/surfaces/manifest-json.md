# Settings surface · implementation brief

Scope: A07 only. Operate mode. This extends the established MyWallpaper settings
surface represented by Taskbar Configurator. The mission fixes that presentation;
there is no replacement identity, standalone settings website or concept seed.
The owner confirmed fluent, expressive motion as default.

## Direction contract

THESIS: Choose motion by intent, then adjust it without programming.

OWN-WORLD: Inherit MyWallpaper's native-only settings renderer, grouped sections,
range/select/boolean/color controls and device snapshots. Native demo buttons
inherit Windows controls; the window content is plainly an owned Win32 sample.

STORY: Pick an ambiance, select applications, control the four moments, try the
window, then reveal custom motion or per-application profiles when needed.

FIRST VIEWPORT: Enable, Ambiance, Vitesse and Amplitude lead; the four transition
switches and application selection follow. Custom details and resource controls
are collapsed, conditional or below this main path. Preview is opt-in.

FORM: Extension of the pinned settings surface. Seed key: not applicable to this
specified extension. Signature interaction: a real captured window funnels into
a chosen edge through Genie, alongside five other native modes.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Proof boundary: SDK validation checks the manifest contract. Runtime frames and
Windows fixtures demonstrate the effects. They are not captures of MyWallpaper's
sidebar; its rendering has not been exercised in this mission. No raster assets
ship in the runtime; evidence images come from native framebuffers.
