# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

The settings are rendered by MyWallpaper's existing settings UI. The effects
and optional test windows are native Windows x64 programs.

## Users

Windows users who want expressive window motion without programming.

## Product Purpose

Configure opening, closing, minimizing and restoring selected application
windows through the ordinary MyWallpaper settings, with useful presets and
readable controls. The owner chose fluent, expressive motion as the default on
2026-10-13.

## Operating Context

The shared mission and Taskbar Configurator establish the settings presentation.
The current decision ledger in MyWallpaper remains the only durable decision
authority. This record captures the brief; it does not ratify launch scope.

## Capabilities and Constraints

At most 100 manifest setting definitions, including sections. Device settings;
no required JSON/CSS. A07 excludes virtual desktop transitions. Runtime proof is
scoped to the actual windows and Windows build tested. Composition hooks and
accelerated/translucent capture require separate qualification.

## Accessibility & Inclusion

Honor Windows' animation preference by default, allow each transition to be
disabled, preserve focus, and keep native overlays inert to keyboard and mouse.
